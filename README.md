# Daily Customer Order Reporting System

A beginner-friendly e-commerce daily order management and daily/weekly PDF reporting web application built with **FastAPI**, **HTML/CSS/JS**, **ReportLab**, **Supabase PostgreSQL**, and **Streamlit**.

---

## 🌟 Features

- 📊 **Interactive Dashboard**: Displays today's live stats (Total Orders, Verified, Pending, Rejected, Total Sales in PKR).
- 🛒 **Order Management**: Add, view, edit, and delete customer orders.
- 🏷️ **Product Catalog & Auto-Pricing**:
  - `Plain Shine` — Rs. 2,050
  - `Needle Texture` — Rs. 2,050
  - `Crocodile Texture` — Rs. 2,050
  - `Snake Texture` — Rs. 2,050
  - `Softy Grain Leather` — Rs. 2,099
  - Selecting a product automatically calculates and populates the amount. Server validates exact pricing on submission.
- 🔍 **Search & Filters**: Search orders by customer name, phone number, tracking ID, product code, or order ID. Filter by status (`All`, `Pending`, `Verified`, `Rejected`) or specific order date.
- 📄 **Daily PDF Report**: Generate and download printable PDF reports for any selected day.
- 📆 **Weekly PDF Report**: Calculate multi-day range metrics (7 days) with daily breakdown tables and download printable PDFs.
- 🎛️ **Streamlit Admin Dashboard**: Alternative lightweight reporting dashboard reading directly from the database.

## 🚀 Setup & Execution Instructions

### 1. Installation

Install all required dependencies:

```bash
pip install -r requirements.txt
```

### 2. Supabase Setup (Optional for Cloud DB)

1. Open your [Supabase Dashboard](https://supabase.com/).
2. Go to **SQL Editor** and execute the queries from [`schema.sql`](file:///C:/Users/MK%20Laptop/.gemini/antigravity/scratch/daily-order-system/schema.sql):

```sql
CREATE TABLE IF NOT EXISTS orders (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    customer_name TEXT NOT NULL,
    phone TEXT NOT NULL,
    tracking_id TEXT NOT NULL,
    product_code TEXT NOT NULL,
    product_name TEXT NOT NULL,
    amount NUMERIC(10, 2) NOT NULL,
    order_date DATE NOT NULL DEFAULT CURRENT_DATE,
    status TEXT NOT NULL CHECK (status IN ('Pending', 'Verified', 'Rejected')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
```

3. Update your `.env` file with your Supabase credentials:

```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-supabase-anon-key
```

*Note: If no Supabase credentials are specified, the system automatically uses a local SQLite database (`orders.db`) for immediate testing out of the box.*

---

### 3. Run FastAPI Backend & Frontend

Launch the FastAPI application:

```bash
uvicorn backend.main:app --reload
```

Open your browser and navigate to:
👉 **`http://localhost:8000`**

---

### 4. Run Streamlit Admin Panel

Launch the Streamlit reporting panel:

```bash
streamlit run streamlit/app.py
```

Open your browser and navigate to:
👉 **`http://localhost:8501`**
